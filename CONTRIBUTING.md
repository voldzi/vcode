# Contributing to VCode

Thank you for helping improve VCode. Clear bug reports, accessibility findings, documentation corrections and focused pull requests are welcome.

## Before opening an issue

1. Search existing issues.
2. Verify the problem on the current public website or default branch.
3. Do not include personal data, credentials, access tokens or private infrastructure details.
4. Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

## Pull requests

Keep changes focused and explain the user-visible result. Run:

```bash
pnpm check
pnpm test
pnpm build
```

Update both Czech and English content where applicable. API, configuration, privacy, security or operational changes must update the corresponding documentation and OpenAPI contract in the same pull request.
