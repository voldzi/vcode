# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send a concise report to [podpora@zeleznalady.cz](mailto:podpora@zeleznalady.cz) with the subject `VCode security report`.

Include the affected URL or component, impact, reproduction steps and any safe supporting evidence. Do not access other people's data, degrade a service, use automated destructive testing or disclose the issue before it is resolved.

We acknowledge actionable reports, assess severity and coordinate a fix and disclosure. We do not promise a bounty programme.

## Supported version

Only the current production release and the default branch receive security fixes.

## Public repository boundary

This repository intentionally excludes credentials, internal hostnames, network addresses and the production inventory. If you find such information in a commit, report it as a security issue rather than repeating it publicly.
