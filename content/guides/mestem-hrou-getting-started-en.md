## Before you start

Bring a charged phone with a browser and an internet connection for loading the game and using external navigation. Public games are free; an account and installation are optional.

**Selected games are available in English.** This guide follows the English game interface. The Czech version has additional modes and controls, so the two guides intentionally differ.

[Open the English games](https://mestemhrou.cz/mestem-hrou/?lang=en).

## 1. Choose a place and a story

1. Browse the English game catalogue and choose a place that interests you.
2. Use **View game** to open a story. Where several games are offered, choose the one you want to play.
3. Review distance, estimated time, access and any **Before you set out** notice. A free game does not guarantee free admission to every venue or an unrestricted route.

A trail prepared from public sources may not have been checked on location. Check its stated status and current conditions before starting.

## 2. Start the game

Select **Start the game** in the trail detail. The first stop opens with navigation options.

## 3. Find the stop

1. Select **Open navigation** to open the destination in an external map service.
2. Go to the place, then return to the game in your browser.
3. Select **I am at the place** to open the question.

If you choose **Follow the Arrow** where offered, allow the supported phone sensors; arrival can open the task automatically. **Use map assistance** returns you to map navigation and manual arrival.

## 4. Look around and answer

1. Read the question and look for the detail at the location.
2. Select an answer; for a cipher, enter the requested word or code. Then choose **Check answer**.
3. If the answer is incorrect, look again and try another answer.
4. For help, select **Show a gentle hint**. Cipher games also offer **Show a stronger hint**.
5. After solving the task, select **Continue to stop…** to move on. Each solved task adds to the story and secret phrase.

This guide does not reveal correct answers or the final secret phrase.

## 5. See the ending or continue later

After the final task, select **See the ending** to read the conclusion.

To return to an unfinished game, reopen it on the same device and in the same browser, then use its continue action. Avoid clearing the browser’s site data while you want to keep your progress.

## Installation and poor connectivity

You can play directly in the browser. Installing the web app is optional; supported browsers may offer an installation or add-to-home-screen action.

The English interface does not currently offer the Czech **Připravit offline** control or all Czech game modes. Do not assume an English trail and its external navigation will work completely without a connection. If you use the Czech interface to prepare offline content, follow the [Czech guide](/navody/mestem-hrou-prvni-vyprava/).
