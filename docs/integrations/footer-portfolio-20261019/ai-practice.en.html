Footer link clicks

On the public home page of AI v práci, we count only clicks on four footer links: Moje porce, Městem hrou, Myslopis and VCode. Each link has its own fixed category; we record only that category and a constant identifier for the public home page. This measurement does not count visits, exercise progress or exercise content. A click indicates interest, not a number of people or use of the destination app.

We do not send original or destination link URLs, URL parameters or fragments, page titles, link text, nicknames, return codes, participant identifiers, chat, notes, answers or any other working content. Administration and private areas are excluded from this measurement. It uses no analytics cookies, local storage, signed-in identity or screen recording.

Requests are handled by the shared VCode/Umami service. On delivery, the server processes technical connection information, particularly the IP address and browser and device type. The IP address is not stored in readable form in the analytics database. A derived identifier changes daily and does not identify a participant account; inferred geographic location is not stored. Operational and security logs are separate from analytics.

Nothing is sent or queued for later delivery when Do Not Track or Global Privacy Control is enabled, or while offline. Navigation never waits for measurement and works when it is disabled. Statistics are accessible only to authorized people after sign-in. Analytics records, including operational backups, are retained for no more than 180 days.
